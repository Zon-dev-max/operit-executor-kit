# 任务五步走·落盘规范（通用主流程 ＋ 落盘执行分支）

版本：v2.4

> 读我的人＝执行项目的 AI。开工前读完，全程照做。
> **定位：横切规范，始终生效**——不依附任何单一任务，凡需落盘的任务都适用。
> 事实来源：真机实测（命令与输出见文末）。
> 与《工作区管理·索引与归档规范》配合：本规范管单项目内部，项目之间的组织/索引/归档/截断由其负责。

## 0. 何时用（触发）
- 任务要**写 / 改 / 生成文件**（报告、代码、配置、角色卡、技能……）
- 要**建 / 整理工作区**、要**跑命令**、要**产出交付物**、要**写契约或交接单**
- 用户没说"目录"二字也算（如"生成个角色卡""把这个结论存下来"）

## 0.1 开工四问（先答完，再动手）

1. 工作区在哪？ → `/sdcard/Download/Operit/workspace/active/<项目名>/`
2. 临时文件放哪？ → 该项目 `tmp/` 下
3. 怎么保证结束不留垃圾？ → 收尾清 `tmp/`、根目录零新增
4. 上下游是什么？ → 只读 `logs/step_<n-1>.md`，不翻长对话；首步（step_1）无上游，绑定用户需求原文即算完成

## 0.2 主流程 · 五步走（通用）

五步走 ＝ **复用 → Refine → Plan → Act → 沉淀**（RPA = Refine-Plan-Act；通用任务主线）。

| 阶段 | 做什么 | 产出 | 判据 |
|---|---|---|---|
| ① **复用** | 先搜已有产出 / 知识 / 记忆，别闭门造车 | 复用清单（用了谁） | 能不重写就不重写 |
| ② **Refine** | 把需求问清、对齐边界与验收 | 目标 / 验收 / 不变量 | 需求不明 → 停下问 |
| ③ **Plan** | 拆小步、定顺序与回滚 | 小步、可验的计划 | 不一口吞 |
| ④ **Act** | 小步执行，每步验证 | 改动 + 验证证据 | 不过 → 停 / 回退 |
| ⑤ **沉淀** | 收尾清理 + 经验回写 | 交接单 / 结论落盘 / 清理临时物 | 不留垃圾 |

**层级嵌套（先读这条，再读 §2）**：五步走＝**任务级**阶段；**每个 step_N 内部跑一遍五段走（读→定→做→验→交，见 §2）**。Act 拆出的小步不另开 step，聚合为同一步内的多个"做/验"循环；step_N 的 n 按交付物粒度计——一次契约锁定＝一个 step，同名 plan/logs 成对开。

**三验（验证门）**：V1 改前基线（记录改前状态与指纹）→ V2 改后结果（命令 / 输出 / 退出码 / 重读）→ V3 反向可行（回滚可执行）。三步观测各记一处：V1 记在契约或"做"段开头，V2/V3 记入交接单【验收证据】。三验不足 → 停，不硬走。

**审批门**：不可逆 / 影响面大 / 偏离既定文档 / 首次遇到 → 停下报告，等授权；授权后不再反复确认。

**契约**：开工先写「目标 + 验收 + 不变量」并锁定；想改 → 停下问。

> 落盘任务里，主流程按下方 §2「五段走」落地：读 → 定 → 做 → 验 → 交。

## 1. 落点（照抄，别试探）

- `/sdcard/Download/<项目名>-交付/` —— 仅放交付成品（见 §1.6），不放临时/中间物；用户另行指定落点时以用户为准

## 1.5 目录式样（照抄，不许自创）

唯一布局 —— **项目名＝任务名（不带日期）**：

```
/sdcard/Download/Operit/workspace/active/<项目名>/
├── plan/step_1.md   step_2.md   …     # 契约，与 logs 1:1 配对
├── logs/step_1.md   step_2.md   …     # 交接单
├── src/…                              # 正式产物（总结/报告/代码）
└── tmp/tmp_<用途>.py                  # 临时文件，收尾清零
```

固定项（写死，改一个＝任务失败）：

| 项 | 值 |
|---|---|
| 工作区父目录 | `/sdcard/Download/Operit/workspace/active/` |
| 四个子目录 | `plan` `src` `tmp` `logs`（全小写，**不新增第 5 个**） |
| 契约 / 交接单 | `plan/step_<n>.md`、`logs/step_<n>.md`，`n` 从 1 连续，同名配对 |
| 临时文件 | `tmp/tmp_<用途>.py`（或 `.sh`） |
| 插件数据 | `plugin_data/<宿主注册的 toolpkg_id>/`（照抄 manifest，不自造） |

禁止：
- 自创目录名、自创层级、给子目录改名
- 在项目根目录直接丢文件（文件只进 `plan/ src/ tmp/ logs/`）
- 把临时文件放 `/tmp`、`/sdcard/Download/`、Operit 根
- 项目名带空格或与任务名不一致

## 1.6 交付与导出（成品去哪）

两类文件分开对待：

| 类别 | 落点 | 生命周期 |
|---|---|---|
| **过程临时**（中间脚本、草稿） | 本项目 `tmp/` | 收尾清零 |
| **交付成品**（要给用户拿走 / 导入 / 分享，如角色卡 JSON、安装包） | **固定交付位** `/sdcard/Download/<项目名>-交付/` | 保留，供用户取用 |

- 交付位是**唯一被允许的 Download 例外**，仅放成品，不放临时/中间物。
- 成品**源**放 `src/`（可再生成）；交付位是导出副本，**文件名**带项目名与时间戳（命名口径见 §3.5 与 §4.5 的分工）。
- 用户另行指定落点时，以用户指定为准并记入交接单。

## 2. 五段走（＝每个 step_N 内部的落地流程）

| 段 | 动作 | 判据 |
|---|---|---|
| 读 | 只读上一份 `logs/step_<n-1>.md`；step_1 无上游，读用户需求原文 | 不翻长对话历史 |
| 定 | 写 `plan/step_<n>.md`（目标/输入/输出/验收/不变量/回滚），写完即锁 | 锁后不改 |
| 做 | 只做本步范围；临时文件全落 `tmp/`；**V1 改前基线在此段开头记录** | 不偷做下一步 |
| 验 | 跑最小验证，记**可复现观测**（V2 改后、V3 反向）：命令 / 工具调用结果 / hash / 重开比对 / 结构化断言，任一即可 | 不过 → 停 |
| 交 | 写 `logs/step_<n>.md`，写完封存 | 后续只读 |

三种状态，别自创第四种：
- 【继续】上一步"下一步"明确无歧义 → 直接干
- 【阻塞】要决策 / 要授权 / 条件不成立 → 停，报告
- 【回退】验证失败 → 按上一步回滚方式退，不硬走

**断层自检（按文件名配对，不只比数量）**：

```bash
for d in /sdcard/Download/Operit/workspace/active/*/; do
  diff <(ls "$d/plan" 2>/dev/null | sort) <(ls "$d/logs" 2>/dev/null | sort) >/dev/null \
    || echo "断层: $d plan=[$(ls "$d/plan" 2>/dev/null | tr '\n' ' ')] logs=[$(ls "$d/logs" 2>/dev/null | tr '\n' ' ')]"
done; echo ok
```

（无输出＝文件名逐一对上；有输出＝该步断层，按列出的文件名补齐再继续。）

**自检时点**：在交段之后跑；中途跑出断层属预期（交单未写），不作故障处理，收尾复跑确认归零即可。

## 3. 交接单模板（`logs/step_<n>.md`，字段全填）

```
- 【步骤编号】step_<n>
- 【上游依赖】哪一步 / 哪个文件 / 哪个指纹（现场算）
- 【做了什么】一句话
- 【产物】src/xxx（保留） / tmp/xxx（待清）
- 【验收证据】（三验分栏，逐栏原样抄真跑过的观测）
  - V1 改前基线：<改前状态 / 指纹 / 基线值表位置>
  - V2 改后结果：<命令 + 原样输出 + 退出码 / 重读比对>
  - V3 反向可行：<一条回滚命令 或「免回滚」判定依据>
- 【回滚方式】级别（R0/R1/R2/R3）+ 一条可执行恢复命令；R0 写「免回滚（删新增物）」
- 【下一步】可执行的原子动作 或 「阻塞：等待 X」
```

## 3.5 产物修订与版本化（改版时照做）

- 改版产物：**绑定父版原文 → 只替换一处通用机制 → 写新版本、不覆盖父版**（**产物文件名**带版本或时间戳；技能名与项目名仍按 §4.5 不带版本——前者是文件名，后者是名称，口径分工不冲突）
- 写完**重开父版与新稿**，打印：路径 / 指纹（现场算）/ 字节数 / 差异
- 体量红线：角色卡正文 ≤8000 字节；技能正文 <500 行且 <5000 tokens
- 超限、或与父版无实质差异 → **停下报告**，不硬写

## 3.6 回滚分级（何时该回滚，别动个啥都回滚）

**默认前进修复；回滚是保底手段，不是默认动作。** 只有"会继续坏 / 不可逆 / 覆盖了既有对象"才预置回滚凭据。

### 先答三问（顺序不能乱）
1. **损失会不会继续扩大？**（错误数据持续写入、外部副作用、不可逆污染）→ 会 → 必预置
2. **改动可逆吗？**（能否一条命令恢复原状）→ 不能 → 必预置；**能但"恢复 > 1 条命令" → 先重新设计动作**，不硬加备份
3. **覆盖了既有可用对象吗？**（现役文件 / 已有配置 / 已有数据）→ 是 → 必留凭据

> 三问全"否"（纯新增、可再生成）→ **无需回滚**，交接单写「R0 免回滚」。

### 分级表（凭据只留一个，够恢复即可）

| 级 | 情形 | 凭据 | 何时留 |
|---|---|---|---|
| **R0 免回滚** | 纯新增文件、`tmp/`、可再生成产物 | 无 | — |
| **R1 版本回滚** | 覆盖 / 替换既有对象（现役文件、角色卡、技能） | 父版整份文件 | 改动前 |
| **R2 配置回滚** | 改配置 / 环境变量 / 状态值 | 契约里的**基线值表**（原值逐字段） | 改动前 |
| **R3 授权回滚** | 不可逆、他方系统、生产库、删除、外发、烧录 | 先停下等授权 + 快照 / 一次性环境 | 授权后 |

### 三条硬约束
1. **凭据只留一个**：父版 或 基线值表 或 快照路径，不叠加。
2. **不留独立回滚脚本**：反向操作写成**一条命令**进交接单，不写 `.sh`。
3. **不做无差别备份**：只备份"将被覆盖的既有对象"；新增物不留副本。

### 交接单回滚栏怎么写
- R0 → `免回滚（纯新增，删新增物即可）`
- R1 → `cp <父版路径> → <现役路径>`（附父版指纹，现场算）
- R2 → `按 plan/step_N.md 基线值表逐字段写回`
- R3 → 授权记录 + 快照路径

## 4. 临时文件

- 命名：`tmp_<用途>.py`（或 `.sh`），唯一、不重名
- 位置：只放 `workspace/active/<项目>/tmp/`
- 生命周期：结束清空（`rm -f`）；有留存价值 → 移 `src/`
- 不得覆盖 `src/` 正式文件

## 4.5 描述与命名（**以后所有描述都按此**）

> 要点如下；完整版可另立《描述标准》文档（项目内有 `src/描述标准.md` 时以其为准）。
1. **一眼答两问**：是什么 ＋ 什么时候用；缺一不合格
2. 对 AI 用**祈使句**：「当…时使用」，不写「本…实现了…」
3. 写**意图与触发词**（含没说出口的近义场景），**不写实现细节 / 版本 / 来源 / 黑话**
4. **宁推不藏**；**短**（技能 description ≤1024 字符）
5. **名称＝用途**，不带版本 / 日期 / 代号（版本进 marks / 备注）；此条指**技能名与项目名**——产物文件名的版本/时间戳见 §3.5，两者不冲突
6. 自检：零上下文的人能否一眼说出"何时该用它"

## 5. 禁止项（违反＝任务失败）

- 跳过 `logs/` 续接对话历史
- 一步做完不写交接单
- 拿"我记得上一步是这样"当依据
- 产物跨目录乱扔（正式进 `src/`，临时进 `tmp/`，成品进交付位）
- 在根目录、`plugins/`、`plugin_data/` 根写东西
- 把交付成品丢进 `tmp/`，或把临时物丢进交付位
- 描述里写版本号 / 来源血统 / 内部黑话
- **无差别**备份副本 / 独立回滚脚本（R1 父版留存、R2 基线值留存属回滚凭据，不在禁列）
- 同一命令或同一错误重复两次还在重试 → 熔断，报阻塞

## 6. 收尾

1. 扫 `tmp/` → 没用的删、有留存价值的移 `src/`
2. 总结写 `src/`（**一份**，不在第二处再抄一遍）
3. **完成核对**：绑定对象未漂移；声称的路径都已重开；字面输出与证据一致；最新任务有已执行结果而非只做准备
   - 回滚栏已按 R0–R3 判定；R1/R2 的凭据（父版 / 基线值表）确实存在且可用
4. **根目录巡检**：查 Operit 根与交付位是否有非预期新增文件，发现即报（他方产物只报不清）
5. 汇报固定行：`当前：<对象> / <已确认结果> / <正在做的动作>`
6. 项目完成后按《工作区管理·索引与归档规范》搬移到 done/YYYY-MM/，并更新 INDEX.md。

## 7. 省 token（硬约束）

- 同一命令、同一错误出现两次 → 停手，不再重试
- **次数口径（重试 / 复读上限）与其他规范或角色卡冲突时，取更严者（次数更少者优先）**
- 遍历/批量/跑脚本，不把大段原文反复塞进对话
- 固定判据（宪法、规范）只引用路径，不每次复制正文
